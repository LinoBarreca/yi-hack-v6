Configurations

In this page you can enable and disable services, change the camera hostname, disable the cloud features and more.

General

Hostname Camera's hostname on the network. Leave blank to generate automatically.
Timezone Timezone. Get your timezone string from this page and copy here.
Disable Cloud Disable the Yi App and all the Cloud features (aka private mode).
Recording without Cloud Enable recording on the SD card even with the Cloud features disabled. (It takes effect only if the "Disable Cloud" option is enabled).
RTSP Enable RTSP Server.
RTSP Stream
Select stream resolution.
RTSP Audio
Enable/disable audio for RTSP stream.
WARNING: this is an experimental feature.
ONVIF Enable ONVIF Server.
ONVIF WS-Discovery Enable WS-Discovery daemon for ONVIF service.
ONVIF Profile
ONVIF Network Interface
Enable/disable time OSD Enable/disable time OSD in the upper left corner.
It works only if the cam doesn't show osd natively.
Snapshot Enable snapshot feature.
If you want to use this feature, enable swap file to avoid memory problems.
Snapshot resolution
Motion/event snapshot resolution. Low uses less memory/CPU.
Snapshot watermark Overlay the timestamp watermark on the motion/event snapshot.

Advanced

SSH Enable or disable the SSH server.
FTP
Enable the FTP server and select the implementation. BusyBox is the lightweight legacy server; Pure-FTPd is the full-featured one.
Telnet Enable or disable the Telnet server.
WARNING: Telnet is NOT a secure protocol and should be avoided. Enable only if it's really necessary.
NTPD Enable or disable the Network Time Protocol Daemon. This is required to sync the time on the camera if the cloud features are disabled.
NTP Server NTP server name.
HTTPD Enable or disable the Web Server.
WARNING: If disabled, you won't have access to this page.
Proxychains-ng Proxychains-ng is a way to bypass the region restrictions imposed by Yi when using a Chinese camera outside China. See the GitHub page for more info on how to configure it.
Recording (NVR)
Record video locally with the built-in recorder (no cloud). Choose where to store the clips: SD card, the network share, or RAM (temporary, lost on reboot - only useful with FTP upload). "Disabled" turns recording off. Set the retention and browse the clips in the Events page.
Swap file
Use a swap file to expand memory (recommended for MQTT/HomeAssistant and snapshots). The swap file lives on the SD card; "Disabled" turns it off.

Network share (CIFS)

Load the firmware from a network shared folder (boot without an SD card) and/or store recordings on it. Uses SMB/CIFS - the same "shared folder" a NAS provides. See the Native NVR guide for the read-only / read-write share layouts.

Boot from network (no SD) Load the firmware from the share below instead of the SD card.
Server (host) Your NAS/server IP address or name.
Firmware share The (read-only) shared folder that holds the firmware.
User
Password
Recordings share (read-write)

Where clips go when Recording (NVR) above is set to Network share. Any field you leave empty is inherited from the firmware share above, so usually you only set the share name. For tighter security use a separate, write-only share/account here (see the Native NVR guide).

Recordings share Empty = record to the firmware share above.
Recordings server Empty = same server as the firmware share.
Recordings user Empty = same user as the firmware share.
Recordings password Empty = same password as the firmware share.

TCP ports

RTSP Port TCP port used by RTSP Server (default 554).
HTTPD Port TCP port used by HTTPD Server (default 80).

Authentication

RTSP / ONVIF Username Username to access RTSP and ONVIF (default empty). The ONVIF stream URL embeds these credentials.
RTSP / ONVIF Password Password to access RTSP and ONVIF (default empty).
Allowed special chars: \ | ! " $ % & / ( ) ' ? ^ [ ] @ < > , ; . : - _
Web Username Username to access the web interface (default empty). May differ from the RTSP/ONVIF one.
Web Password Password to access the web interface (default empty).
Allowed special chars: \ | ! " $ % & / ( ) ' ? ^ [ ] @ < > , ; . : - _
Root Password Password for SSH, Telnet and FTP root user (default empty).
Allowed special chars: \ | ! " $ % & / ( ) ' ? ^ [ ] @ < > , ; . : - _
